Northern Mariana Islands CPA License Renewal Deadline

Northern Mariana Islands CPA license renewal

Certificates and firm permits both expire exactly 3 years from that specific license's own issuance or last-renewal date (Public Law 13-52 Sec. 6(b) for certificates, Sec. 7(b) for firm permits, worded identically) -- the month and day carry forward unchanged, only the year advances. Filing deadlines are set relative to each license's own expiration date, not a shared calendar window (NMIAC 1-10-605(a) individual; 1-10-701(a) firm).
